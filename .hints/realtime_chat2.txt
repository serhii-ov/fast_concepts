Here’s a ready-to-go starter structure for a FastAPI E-commerce Backend, using clean architecture, JWT authentication, 
SQLAlchemy (async), and modular app design — perfect for real-world use and portfolio showcasing.

✅ Core Features
Modular app design with separation of concerns
User registration, login with JWT
Product catalog
Cart and order management
Admin panel basics (via roles or flags)
Async SQLAlchemy + Alembic for migrations
Dockerized, .env based configuration

main.py
from fastapi import FastAPI
from app.api.v1 import (
    routes_auth, routes_users, routes_products,
    routes_cart, routes_orders
)

app = FastAPI(title="FastAPI E-commerce Backend")

# API routing
app.include_router(routes_auth.router, prefix="/api/v1/auth", tags=["Auth"])
app.include_router(routes_users.router, prefix="/api/v1/users", tags=["Users"])
app.include_router(routes_products.router, prefix="/api/v1/products", tags=["Products"])
app.include_router(routes_cart.router, prefix="/api/v1/cart", tags=["Cart"])
app.include_router(routes_orders.router, prefix="/api/v1/orders", tags=["Orders"])

Dockerfile
FROM python:3.10-slim
WORKDIR /app
COPY . .
RUN pip install --no-cache-dir -r requirements.txt
CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000", "--reload"]


docker-compose.yml
version: "3.8"
services:
  db:
    image: postgres:13
    restart: always
    environment:
      POSTGRES_USER: user
      POSTGRES_PASSWORD: password
      POSTGRES_DB: ecommerce_db
    volumes:
      - postgres_data:/var/lib/postgresql/data
  web:
    build: .
    ports:
      - "8000:8000"
    depends_on:
      - db
    env_file:
      - .env
volumes:
  postgres_data:

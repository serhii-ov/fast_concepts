Here’s a ready-to-go starter structure for a FastAPI SaaS API for Task Scheduling, ideal for offering users a scalable, 
multi-tenant system to create, schedule, and manage recurring or one-time tasks with background execution support.

✅ Core Features
Multi-user (SaaS) architecture
User authentication via JWT
Create/update/delete scheduled tasks
Background task execution using Celery
Periodic task scheduling using Celery Beat
Task status tracking and notifications
PostgreSQL + SQLAlchemy (async)
Modular app layout ready for production

main.py
from fastapi import FastAPI
from app.api.v1 import routes_auth, routes_users, routes_tasks

app = FastAPI(title="SaaS Task Scheduler API")

app.include_router(routes_auth.router, prefix="/api/v1/auth", tags=["Auth"])
app.include_router(routes_users.router, prefix="/api/v1/users", tags=["Users"])
app.include_router(routes_tasks.router, prefix="/api/v1/tasks", tags=["Tasks"])

models.py
class Task(Base):
    __tablename__ = "tasks"

    id = Column(Integer, primary_key=True, index=True)
    title = Column(String, nullable=False)
    run_at = Column(DateTime, nullable=False)
    frequency = Column(String, nullable=True)  # e.g., 'daily', 'weekly'
    status = Column(String, default="PENDING")
    owner_id = Column(Integer, ForeignKey("users.id"))
    owner = relationship("User", back_populates="tasks")

periodic.py
from app.core.celery_app import celery

@celery.on_after_configure.connect
def setup_periodic_tasks(sender, **kwargs):
    sender.add_periodic_task(60.0, check_expired_tasks.s(), name='check every 60s')

@celery.task
def check_expired_tasks():
    print("Checking for expired tasks...")

docker_compose.yaml
version: "3.9"

services:
  api:
    build: .
    command: uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
    volumes:
      - .:/code
    ports:
      - "8000:8000"
    env_file:
      - .env
    depends_on:
      - db
      - redis

  db:
    image: postgres:14
    environment:
      POSTGRES_USER: user
      POSTGRES_PASSWORD: password
      POSTGRES_DB: saas_tasks

  redis:
    image: redis:alpine

  celery_worker:
    build: .
    command: celery -A app.core.celery_app.celery worker --loglevel=info
    depends_on:
      - redis
      - db

  celery_beat:
    build: .
    command: celery -A app.core.celery_app.celery beat --loglevel=info
    depends_on:
      - redis
